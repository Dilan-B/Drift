Drift

Earn your screen time by completing real tasks.

How it works

  • Create tasks and complete them to earn screen time minutes
  • Pick which apps to block using Apple's Screen Time API
  • Apps stay blocked until you've put in the work
  • Challenge friends and hold each other accountable
  • Build productive habits without going cold turkey
